# Security

Please **do not** open a public GitHub issue for a vulnerability.

Email the maintainer through the GitHub account that owns this
repository, or open a **private** security advisory on GitHub.

Include:

- the affected SHA or release
- a minimal reproduction
- impact (what an attacker can do)

We will acknowledge receipt and work on a fix before any public
disclosure of exploit details.

This demo build is synthetic. Do not send real personal data with a
report.
